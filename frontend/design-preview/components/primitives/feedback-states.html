Feedback States

Four real components under src/app/components/primitives/: empty-state, skeleton-loader, toast and no-network-banner. Markup, classes and animation keyframes below are copied verbatim from each component's template and src/styles.scss.

Empty State

app-empty-state - host renders role="region" with aria-label falling back to "Empty state" when no title is supplied. Shows an illustration image when given, otherwise an emoji icon (default 📭) that gently pulses via empty-state-icon-pulse. Optional actionLabel renders a primary-styled button emitting actionClicked. The whole block fades in on mount with empty-state-fade-in.

Skeleton Loader

app-skeleton-loader - a template-less component; everything renders on the host itself via host bindings, sized with height / width / borderRadius style bindings (default 16px / 100% / 8px). variant: text (rounded), circle (rounded-full) or rect (default, no extra radius class beyond the style-bound one). Host is aria-hidden="true" with role="presentation" so screen readers skip it entirely, plus an aria-label of "Loading placeholder" for tooling that still inspects it.

Toast

app-toast - a single global host, normally mounted once and fixed to top-10 inset-x-0, rendering every entry in the app-wide toastsSignal from toast.service.ts. type is info / error / success (no dedicated warning type exists on the service). Each toast slides down on entry via animate-slide-down; the outer container is pointer-events-none so only the toast pills themselves (pointer-events-auto) are interactive, letting clicks pass through to the page behind them.

No Network Banner

app-no-network-banner - reads NetworkStatusService.isOnline directly and renders nothing at all while online (no placeholder, no reserved space). When offline it fixes a role="alert", aria-live="assertive" bar to top-0 inset-x-0 in bg-danger, so it interrupts screen readers immediately rather than waiting to be polled. Text is translated via no_network_banner.message, never hard-coded.
