Buttons

Three real button primitives, each its own standalone component under src/app/components/primitives/. Markup and classes below are copied verbatim from each component's buttonClasses() computed signal, not hand-approximated.

Primary

app-button-primary - size: sm / md (default) / lg. Solid bg-primary fill, rounded-app, shadow-card that lifts to shadow-lift on hover. Disabled swaps to flat surface-200 with no shadow.

Sizes

Disabled

Secondary

app-button-secondary - same size options as primary. Flat surface-100 fill with a same-tone border, hover moves to surface-50 (a real fix noted in the component's own comments: hover and base used to resolve to the same shade). Also accepts ariaLabel and ariaPressed for icon-only or toggle usage - no separate visual style for the pressed state, it is purely the aria-pressed attribute.

Sizes

Disabled

Gradient (VIP / gift CTA)

app-gradient-button - size: sm / md (default) / icon (fixed 40×40 square for an icon-only trigger). Deliberately rounded-pill, not rounded-app like the other two - per the component's own source comment, the pill shape itself signals "VIP/gift CTA" independently of the gold-to-accent gradient fill. Focus ring uses ring-vip rather than ring-primary.
