Overlays & Menus

Two real components under src/app/components/primitives/: dialog and context-menu. Both are shell-only components - backdrop, focus handling, ARIA wiring and dismiss behaviour - that consumers fill via ng-content. Markup and classes below are copied verbatim from each component's template and from report-user-modal / message-context-menu, the components that actually consume them today.

Dialog

app-dialog - a shared accessible dialog shell built on @angular/cdk/a11y's CdkTrapFocus rather than the full CDK Overlay service, per the component's own doc comment, since every existing hand-rolled modal already used the same declarative open-signal-in-template pattern. size: sm / md (default) / lg, mapped to sm:max-w-sm / sm:max-w-md / sm:max-w-lg. Sheets up from the bottom on mobile (rounded-t-sheet) and centres with full rounded-sheet corners at sm+. Backdrop click and Escape both call dismissed.emit(), gated by the dismissible input (default true) - the backdrop itself is deliberately not a keyboard tab stop, since Escape is already the keyboard equivalent of a backdrop click. Locks document.body scroll for as long as any instance is open. Header, body and footer markup are entirely up to the consumer; the one real call site, report-user-modal, is the source for the header/body/actions pattern shown below.

Context Menu

app-context-menu - a position-anchored menu shell for "long-press / secondary click a message" style menus, per the component's own doc comment written to replace hand-rolled versions across message-context-menu, chat-context-menu and long-press-context-menu. Positioned at an arbitrary x/y (the triggering event's coordinates) rather than centred like app-dialog. Sets role="menu" on the panel and moves focus to the first [role="menuitem"] child on open - a real accessibility improvement the doc comment notes over the hand-rolled menus it replaces, none of which set menu roles or moved focus at all. Full roving-tabindex arrow-key navigation via CDK's ListKeyManager is called out as a documented follow-up, not yet built.
