Chips, Pills & Badges

Four real components under src/app/components/primitives/: chip, pill, scrollable-pills and language-picker. Markup and classes below are copied verbatim from each component's *Classes() computed signal or template.

Chip

app-chip - variant: default / outlined / primary, each with a selected boolean (the primary variant has no separate selected style, it is already a solid fill). Renders as a role="button" span with tabindex="0" so it is keyboard-activatable without being a native <button>. Optional removable input adds an inline ✕ button that stops propagation before emitting removed, so removing never also fires clicked.

Pill

app-pill - colour: primary / success / warning / danger / info / neutral (default). size: sm / md (default). Per the component's own source comment, colours used to be looked up via I18nService.translate('pill.colour_' + colour) against hard-coded Tailwind classes smuggled into the translation dictionary; it is now driven directly by Relay tokens so dark-mode fills automatically pair with on-fill for correct contrast, with no i18n involvement.

Scrollable Pills

app-scrollable-pills - a horizontally-scrolling role="radiogroup" of native <button> elements, each role="radio" with aria-checked reflecting the required selected input. pills takes an array of id/label pairs; picking one emits pillPicked (renamed from a generic select to avoid colliding with the native DOM event of the same name). Scrollbar is hidden cross-browser via a component-scoped .hide-scrollbar style, not a Tailwind utility.

Language Picker

app-language-picker - a trigger button (aria-haspopup="dialog", aria-expanded bound to the internal isOpen signal) that opens a full-screen modal listing every code in ALL_LANGUAGE_CODES, named and searchable via native Intl.DisplayNames rather than a hard-coded language name table. Each result shows a flag emoji from the internal getLanguageFlag() lookup, the English name and the language's own native name, filtered client-side against searchQuery. Selecting emits languageSelected with the ISO code and closes the modal.
