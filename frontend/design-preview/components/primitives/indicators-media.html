Indicators & Media

Four real components under src/app/components/primitives/: fluency-indicator, typing-indicator, audio-equalizer and lottie-player. Markup, classes and animation keyframes below are copied verbatim from each component's template and inline styles.

Fluency Indicator

app-fluency-indicator - a compact, non-interactive role="img" summary of a partner's native versus target languages, separated by a ⇌ glyph. Flags come from the same getLanguageFlag() lookup used by language-picker. Target language codes are tinted text-neon-violet to visually separate them from the (default text colour) native codes; multiple codes on either side are joined with a muted | divider. The whole thing collapses to a single aria-label summary sentence for assistive tech rather than being read glyph by glyph.

Typing Indicator

app-typing-indicator - renders nothing when typingUsers is empty (visible() gates the whole template). Shows up to maxVisible (default 3) overlapping avatars plus a +N badge for the remainder, three neon-violet dots bouncing on staggered delays, and a translated status sentence (typingIndicator.single / .multiple / .many) whose params are built entirely from real display names, never hard-coded English. role="status" with aria-live="polite" so screen readers hear the same summary. Sits on a dark surface-900/80 scrim regardless of theme, since it is designed to overlay message content.

Audio Equalizer

app-audio-equalizer - barCount (default 4) bars using bg-current, so the colour comes from whatever text-* class the consumer wraps it in (the one real call site, audio-room, leaves it on the ambient default text colour of the speaker tile). isActive toggles between animated bars (staggered animation-delay per bar, computed as -(i × 0.18) % 1 seconds so they never all peak in sync) and a flat, dimmed opacity-40 row pinned to 4px tall when the speaker is silent.

Lottie Player

app-lottie-player - a thin wrapper around the lottie-web library. Its own template is a single empty <div class="w-full h-full">; everything visible is SVG that lottie.loadAnimation() renders into that div at runtime from a required animationData JSON input, with loop / autoplay / speed inputs and an animationComplete output tied to the player's own complete event. Because the rendered content is entirely runtime-generated from whatever Lottie JSON is passed in, there is no static markup or fixed class list to reproduce here - the box below stands in for the w-full h-full container only, not for any specific animation.
