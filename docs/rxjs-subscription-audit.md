# RxJS subscription audit

Issue 2040 audits every long-lived subscription in the Angular frontend, migrates the ones that have a clean signal equivalent, and stops new unreviewed ones from appearing. The change is frontend only: it adds no API, schema, persistence or privileged behaviour, so there is nothing to migrate or audit server-side. Rollback is a plain revert.

## Method

`frontend/src` production code was searched for `.subscribe(`, `new Subject`, `new BehaviorSubject`, `setInterval`, `.toPromise()` and `rxjs/operators` imports. The admin portal (27 production files) has no subscriptions, `Subject`s, intervals or window listeners. Each frontend site was read together with its spec and its teardown path, then migrated or recorded as an accepted exception.

`rxjs/operators` imports, `.toPromise()` and `BehaviorSubject`, `ReplaySubject` and `AsyncSubject` were already absent and are now enforced as zero-tolerance rules.

## Findings fixed

| Area                                                                            | Finding                                                                                                                                                                                                                                     | Change                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CentrifugeService.events`                                                      | Every realtime publication on every channel was appended to a signal array for the whole session, and the array was copied on each message. Memory grew without bound and the copy cost grew with it. Nothing in production reads the list. | The list is now a bounded window of the latest `MAX_RETAINED_EVENTS` (100) publications. See [Centrifugo client resilience](centrifugo-client-resilience.md).                                                                                                                                                                                                                                                                                  |
| Call clocks in `VoipCallComponent`, `VideoCallComponent` and `VideoCallService` | Each held an `interval(1000).subscribe()` handle that had to be released by hand in `ngOnDestroy` or `endCall`.                                                                                                                             | They use `elapsedSeconds()` (`core/reactive/elapsed-seconds.ts`), a `toSignal` timer owned by the component or service injector. It cannot start after destruction, restarts from zero on reconnect and reads the wall clock, so a throttled background timer no longer under-reports a call. `VideoCallState.callDuration` moved to the `VideoCallService.callDuration` signal, which also stops rewriting the whole call state every second. |
| `ClassroomsMarketplace`                                                         | Polled `store.activeRooms()`, which is already a signal, every five seconds through `interval().subscribe()`.                                                                                                                               | `rooms` is a `linkedSignal` that follows the store whenever it has rooms and keeps the HTTP or offline-cache listing while it is empty. `createClassroom` no longer prepends the new room itself, because the store already does and the linked signal would list it twice.                                                                                                                                                                    |
| `CoinEconomyTourService`                                                        | Stored a subscription whose handlers did nothing. `JoyrideService.startTour()` already subscribes to the tour itself.                                                                                                                       | The subscription and its bookkeeping are removed.                                                                                                                                                                                                                                                                                                                                                                                              |
| `SrsTourService`                                                                | Started a tour from a raw `setTimeout` inside a `then`, with an untracked subscription and no guard against a double click.                                                                                                                 | One awaited flow: navigate, settle, run the tour with `lastValueFrom`, mark it seen. A second click while a request is pending is ignored, a failed navigation neither starts nor marks the tour, and no timer or subscription outlives the call. `startTour()` now returns a promise.                                                                                                                                                         |
| `SwUpdateService.initialise()`                                                  | Calling it twice subscribed to both service-worker streams twice, doubling the log line and the forced reload.                                                                                                                              | Repeat calls are ignored.                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `DiscoveryService.findPartners`                                                 | Bridged `AbortSignal` to RxJS with a `Subject` and an abort listener that was never removed after a normal response.                                                                                                                        | `takeUntil(fromEvent(abortSignal, 'abort'))` removes the listener when the request settles.                                                                                                                                                                                                                                                                                                                                                    |

## Follow-ups not done here

- Nine services still return `Observable<T>` from `HttpClient` calls (`lessons`, `help-centre`, `version`, `mock-fixtures`, `pronunciation`, `proficiency`, `events`, `study-streak` and `ApiService.getObservable`). They complete after one emission and cannot leak, so convert them to promises as their callers are touched.
- Five `offline-*` services register `online` and `offline` window listeners only to copy `NetworkStatusService.isOnline()` into a separate writable `isOfflineMode` signal. A `computed()` removes both the listeners and the duplicated state, but `clearAll()` writes that flag today, so it needs its own change.
- Delete the unreferenced `centrifugo.service.ts`.
- `IncomingCallComponent` is not rendered anywhere. If it is ever wired in, it and `AppComponent` would both claim the primary handler for the `user_<id>` channel and replace each other, so one of them should use `CentrifugeService.listen()` instead of `subscribe()`.
- The Supabase client keeps its own 30 second auth refresh interval for the life of the app. It is third-party code and out of scope.

## Guard

`npm run check:rxjs-subscriptions` runs inside `frontend` `lint` and `lint:check`, so CI enforces it through the static-analysis job. Its regression tests run in the `pretest` chain of `npm test`.

- Zero tolerance, no baseline: `rxjs/operators` imports, `.toPromise()`, `BehaviorSubject`, `ReplaySubject`, `AsyncSubject`.
- Ratcheted: `.subscribe(`, `new Subject` and `setInterval(` per file, compared with `frontend/scripts/rxjs-subscriptions.baseline.json`. Comments, strings and template literals are ignored.
- A new call site fails until the same change adds a baseline entry with a `teardown` and a `reason`. Removing or migrating a site fails until its entry is lowered or deleted, so the baseline can only shrink.

## Patterns to use instead

- Time since something started: `elapsedSeconds(active)`.
- A local list that should follow a store signal but stay writable: `linkedSignal`.
- An Observable consumed by a template or computed value: `toSignal()` or `rxResource()`.
- A one-shot Observable inside an async function: `firstValueFrom()` or `lastValueFrom()`.
- A subscription that cannot be avoided: `takeUntilDestroyed()`, then a baseline entry.

## Verification

- `ng test --include` for the touched specs: `elapsed-seconds`, `voip-call`, `video-call`, `video-call.service`, `classrooms-marketplace`, `sw-update`, `centrifuge`, `discovery.service`, `srs-tour` and `coin-economy-tour`.
- `node --test scripts/check-rxjs-subscriptions.test.mjs`, including a test that the committed baseline matches the real tree.
- ESLint over every edited file.
