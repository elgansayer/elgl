# Consolidated Backlog: Performance and UX Improvements

## Objective 1: Optimise Rendering for Data-Heavy Views
**User Outcome:** Users experience smooth scrolling, lower memory usage, and no UI lag when viewing extensive chat histories or reading long texts on both mobile and desktop browsers.

**Acceptance Criteria:**
- [ ] Users can scroll through large chat histories smoothly without performance degradation.
- [ ] Reading extensive texts renders without causing browser lag or high memory consumption.

## Objective 2: Overhaul Communities Navigation and Layout
**User Outcome:** Users can easily navigate between broad communities and specific groups/channels through a dense, structured, and responsive layout, with clear active states and activity notifications.

**Acceptance Criteria:**
- [ ] The communities navigation provides a clear hierarchy between communities and groups on all device sizes.
- [ ] Users can easily identify which community or group they are currently viewing.
- [ ] Users are notified of new activity within communities and groups.

## Objective 3: Robust Error Handling for Community Operations
**User Outcome:** Users receive clear, immediate feedback if community creation or deletion fails, preventing confusion and stuck loading states.

**Acceptance Criteria:**
- [ ] Users see clear error messages if creating a community fails.
- [ ] Users see clear error messages if deleting a community fails.
- [ ] The UI remains responsive and does not lock up when an error occurs.
