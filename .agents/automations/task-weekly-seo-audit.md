# Weekly SEO & Meta Tag Audit

## Objective
Ensure the web client retains high discoverability for user profiles and public moments.

## Instructions
1. Audit the Angular `index.html` and router components for dynamic meta tag updates.
2. Ensure `Title` and `Meta` services correctly update descriptions for public moments and user profiles.
3. Ensure proper OpenGraph (OG) images are generated or linked via Cloudflare R2 assets.
4. Verify accessibility and semantic HTML (`<h1>`, `<article>`) remain intact.
