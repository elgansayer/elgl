# Daily Documentation & SPEC.md Sync

## Objective
Ensure the architectural blueprint and backlog are always a source of truth.

## Instructions
1. Review the git commit log for the past 24 hours.
2. Update `SPEC.md` if any new database tables, Centrifugo payload types, or backend integrations were introduced.
3. Update `TODO.md` (or `.tasks/` directory) to move completed items out of active and into completed.
4. Review the `AGENTS.md` engineering constitution and suggest amendments if a new pattern (like a new Angular Signal wrapper) emerged as a standard.
5. Create a clean commit for these documentation updates.
