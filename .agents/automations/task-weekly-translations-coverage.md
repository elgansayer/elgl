# Weekly Translation Coverage Report

## Objective
Ensure parity across all supported language localizations.

## Instructions
1. Compare the primary English JSON dictionary file with all other supported languages (e.g., Arabic, Spanish, French).
2. Identify missing translation keys.
3. Integrate with DeepL/Azure (or mock) to auto-translate the missing keys.
4. Validate that Arabic/Hebrew/Persian strings render correctly in the RTL UI layout.
