## 2026-07-30 - Adding aria-labels to icon buttons\n**Learning:** It's important to only add aria-labels to buttons that are truly icon-only. If a button already has translated text content (e.g. `{{ 'common.close' | t }}`), adding a hardcoded aria-label overrides the localized text with English for screen reader users, breaking accessibility for non-English users.\n**Action:** Verify if a button contains actual text or text via translation pipe before adding an aria-label. Use `[attr.aria-label]="'key' | t"` if the label needs to be localized.
