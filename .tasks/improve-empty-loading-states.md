* Priority: "Medium Impact"
* Description: Standardize and improve the empty states, loading skeletons, and error handling across the application to provide a smoother and more polished user experience when data is fetching or unavailable.
* Technical Implementation: Create a generic `skeleton-loader.component.ts` that accepts properties for shape (circle, rectangle), width, and height. Replace standard "Loading..." text in components (like `discovery.component.ts`) with these skeleton UI placeholders that use a CSS shimmer animation (`@keyframes shimmer`). For empty states, design a reusable `empty-state.component.ts` that includes an illustration slot, a title, a description, and a primary action button (e.g., "Adjust Filters"). Implement global error handling interceptors in Angular that display non-intrusive toast notifications rather than full-page blocks.
